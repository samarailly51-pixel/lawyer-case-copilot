# 交通事故人伤专业工作流

专业节点在案件类型为 `traffic_injury` 时运行：

```text
事故信息 → 责任材料整理 → 伤情治疗 → 医疗费用
→ 保险与鉴定信息 → 赔偿项目矩阵 → 完整性规则
→ 专业风险 → 律师人工复核
```

系统只整理事故认定材料中的责任记载，不自行认定责任；只整理诊断和鉴定原文，不形成医疗诊断或伤残等级判断；只列出赔偿项目所需事实、证据和参数，不自动判定项目成立或计算金额。

证据完整性规则位于 `backend/rules/traffic_injury/`。规则输出必须包含规则 ID、触发依据、严重级别和人工复核要求。赔偿标准、地区参数和个人经验不得写死在 Prompt。
