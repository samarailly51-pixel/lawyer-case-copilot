# 通用办案工作流

```text
案件录入 → 材料处理 → 事实提取 → 时间线 → 主体关系
→ 通用争议分析 → 证据矩阵 → 知识检索 → 风险与缺口
→ 任务规划 → 辅助报告 → 律师复核
```

每条提取事实保存事实类型、内容、日期或金额、置信度、冲突状态和材料引用。时间线只从有日期的事实生成；缺少日期的材料记载保留在事实区。

争议焦点只描述可能问题、当前材料、信息缺口、可能抗辩方向和律师待判断问题，不输出确定责任结论。证据矩阵连接材料、证明目的和律师确认状态。

MVP 对非交通事故案件使用通用节点。合同 Demo 额外展示服务成果与验收材料缺口；这不是对合同责任的法律判断。
