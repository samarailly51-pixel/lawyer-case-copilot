# 交通事故人伤业务经验预留

本文件等待项目所有者根据真实且已经脱敏的个人办案经验补充。当前不提供具体业务结论。

建议按以下结构记录：

1. 实际案件材料分类经验；
2. 常见材料缺失及发现时点；
3. 常见证据冲突和核查路径；
4. 接案、协商、鉴定、诉讼的关键节点；
5. 保险公司与伤者之间常见争议；
6. 异常场景、适用地区和规则有效期；
7. 必须强制人工复核的高风险情况；
8. 规则依据、来源、版本和维护人。

补充内容应区分个人经验、材料事实、外部规则和律师最终判断。

## 经验采集工作表

每次只记录一个可验证场景，并填写：

| 字段 | 说明 |
|---|---|
| 场景名称 | 律师在什么办案阶段遇到什么情况 |
| 触发材料 | 依赖哪些材料或字段，不得只写主观判断 |
| 排除条件 | 哪些情况下不能触发 |
| 风险级别 | 仅表示核查优先级，不表示法律后果 |
| 律师动作 | 需要核实、补充或询问什么 |
| 强制复核 | 是否必须由案件负责律师处理 |
| 适用地区 | 未确认时标记“待核验” |
| 经验来源 | 脱敏案例、内部流程或外部公开来源 |
| 版本与维护人 | 便于过期检查和回滚 |

## 从经验到规则的发布流程

```text
脱敏经验记录
→ 项目所有者确认
→ 转换为 disabled 草稿
→ 虚构案例回归测试
→ 律师复核触发与提示文案
→ 标记地区、有效期和版本
→ 手动启用
```

任何缺少来源、适用范围或复核要求的草稿都不得启用。
