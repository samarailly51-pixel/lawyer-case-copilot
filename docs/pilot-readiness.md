# 内测与上线准入

## 当前结论

项目已达到“作品集展示 + 完全虚构数据验收 + 受控律师内测准备”阶段，尚不应直接承载真实客户案件或对外提供法律服务。

代码已经具备真实上传路径、材料来源校验、人工复核、租户权限、对象存储、恶意文件扫描、审计、规则校验、数据保留和生产配置门禁。仍缺少的部分主要是不能由仓库替代的业务与组织输入。

## 三道门

### 1. 作品集公开 Demo

- 只使用仓库内完全虚构案例；
- `PUBLIC_DEMO_READ_ONLY=true`；
- `MODEL_PROVIDER=mock`；
- 不开放上传、复核、成员管理等写操作；
- 可使用 Render 免费实例，接受休眠和冷启动。

### 2. 受控律师内测

- 部署在受控网络和账号体系中；
- 仅使用明确授权且完成脱敏的测试材料；
- 开启认证、租户隔离、对象加密和 ClamAV；
- 律师逐条确认 AI 事实、风险和知识引用；
- 先完成 20–50 份脱敏案件的标注评测；
- 建立错误登记、停用和事件响应流程。

### 3. 真实案件生产使用

除全部代码门禁通过外，还必须由组织确认：

- 隐私、保密、数据跨境和供应商数据处理协议；
- 部署区域、模型留存/训练政策和分包商；
- 备份恢复目标、删除保留义务和日志留存；
- 经律师审核的个人经验规则和适用边界；
- 真实脱敏评测达到组织设定的阈值；
- 等保或其他适用的安全合规要求；
- 明确的人工复核责任、故障降级和停用机制。

## 自动检查

管理员通过设置页或 `GET /api/system/readiness` 查看：

- 登录认证和 JWT 密钥；
- PostgreSQL；
- S3/MinIO 与加密；
- ClamAV fail-closed；
- 持久队列 Worker；
- 外部模型授权与脱敏边界；
- 数据保留周期；
- 个人经验规则结构和启用状态。

生产环境设置 `APP_ENV=production` 与 `ENFORCE_PRODUCTION_READINESS=true` 后，任何 fail 项都会阻止 API 启动。warn 项仍需负责人确认和记录。

## 真实评测模板

真实脱敏评测至少记录：

| 维度 | 建议指标 |
|---|---|
| 材料分类 | 每类 precision / recall、无法分类率 |
| 事实提取 | 字段级 precision / recall、来源精确匹配率 |
| 时间线 | 日期准确率、事件遗漏率、冲突发现率 |
| 医疗费用 | 金额/票据号准确率、重复与缺失发现率 |
| 风险规则 | 命中率、误报率、漏报严重度 |
| 人工复核 | 平均修改率、关键字段驳回率、单案节省时间 |
| 安全边界 | 无来源输出拒绝率、敏感信息外发测试、注入攻击拦截结果 |

阈值必须由项目所有者和试点律师共同制定，仓库不会伪造准确率或业务效果。
