# 可控内测试点清单

本清单用于把作品集 MVP 推进到受控试点，不代表系统已经适合直接处理真实案件。

## 试点前准入

- [ ] 试点材料使用目的、授权范围、保存期限和删除责任已书面确认；
- [ ] 直接标识符与可组合识别信息已脱敏；
- [ ] 外部模型、OCR、存储和日志服务的数据流已经审批；
- [ ] 个人经验规则由项目所有者填写，并由第二名律师复核；
- [ ] 评测阈值、严重错误定义和停止条件由试点律师确认；
- [ ] 备份恢复、访问日志和数据删除完成演练。

## 单案验收

- [ ] 所有关键事实均能定位到文件、页码和引用片段；
- [ ] 低 OCR 置信度页面已对照原图复核；
- [ ] 冲突、缺失材料和高风险项已逐项处理；
- [ ] 法律知识引用的效力、地区和更新时间已核验；
- [ ] 报告草稿已经案件负责律师接受、修改或驳回；
- [ ] 未将辅助输出当作责任认定、医疗诊断或正式法律意见。

## 指标披露

真实案例评测报告必须同时披露样本量、案件阶段分布、材料类型分布、标注与复核人员、模型/Prompt/规则版本、precision、recall、F1、人工修改率和严重错误清单。阈值留待试点律师确认，仓库不预设业务准确率。
