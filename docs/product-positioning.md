# 产品定位

Lawyer Case Copilot 不是普通法律问答机器人，而是围绕一个具体案件持续运行的案件工作空间。

目标用户是案件负责律师、律师助理和案件协作团队。MVP 聚焦材料整理、事实提取、时间线、证据核查、争议点提示、任务规划和辅助报告，不代替律师形成正式法律意见。

产品由通用律师办案能力和交通事故人伤专业模块组成。合同、劳动、一般民事及其他案件在第一阶段使用通用工作流；交通事故人伤案件由领域路由器加载专业节点和独立规则。

项目展示重点：

- AI 产品：清晰的人机边界、复核闭环和可解释交互；
- Agent 产品：结构化节点、状态编排、回放、重跑及错误处理；
- 企业 AI 应用：模型适配、数据追溯、安全控制和领域插件设计。
