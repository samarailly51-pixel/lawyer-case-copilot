# 安全边界

## 产品声明

- 仅提供办案辅助，不构成正式法律意见；
- 不代替案件负责律师；
- 不自动作出事故或法律责任认定；
- 不自行认定医疗诊断或伤残等级；
- 信息不足时明确提示缺口，不生成确定结论；
- 真实材料必须获得授权并在必要时脱敏。

## 技术措施

- 限制文件类型和大小，保存 SHA-256；
- 文档内容按不可信输入处理，禁止其中指令改变系统边界；
- 检测常见 Prompt Injection 表达并标记人工检查，材料中的指令永远只作为数据；
- 结构化模型输出通过 Schema 校验；
- OCR/解析失败进入人工处理，不转化为事实；
- 没有来源的关键结果显示明显提示；
- API Key 仅从环境变量读取，不写入日志和数据库；
- 外部模型读取案件材料采用默认关闭的显式授权开关；
- 模型事实引用必须能在对应材料原文中逐字验证，否则拒绝入库；
- 知识引用必须携带时间、地区、适用范围及过期风险；
- 关键操作和律师复核写入审计记录。

生产化还需增加恶意文件扫描、传输和静态加密、密钥托管、访问控制、租户隔离、数据删除策略和供应商数据处理评估。
