# Demo 指南

## 合同纠纷案例

1. 从案件工作台进入“青禾餐饮品牌设计服务合同纠纷（虚构）”；
2. 在材料中心查看合同、付款凭证和沟通记录；
3. 在事实与时间线查看签约、付款、交付和异议；
4. 点击事实下方的材料引用，打开原文定位抽屉；
5. 在主体关系和办案任务页面查看通用协作能力；
6. 打开报告中心查看材料引用目录和通用辅助分析报告。

## 交通事故人伤案例

1. 进入“林某交通事故人伤案件（虚构）”；
2. 查看事故认定、住院病历、医疗票据、费用清单、收入及保险材料；
3. 在专业分析中查看事故信息、治疗和 13 类赔偿项目；
4. 查看缺失护理期限依据、住院与开票日期差异；
5. 查看后续腰痛与事故关联是否成立的强制人工核查项；
6. 在 Agent 执行页面重跑一个节点；
7. 在律师复核中心批量处理结果、修改一项内容并查看版本历史；
8. 在专业分析页输入律师自行确认的参数，演示“只做算术、不自动适用规则”的情景测算；
9. 在报告中心打开材料引用目录并导出 DOCX。

所有案例、姓名、公司、医院、保险机构、地点、编号和金额均为完全虚构的演示数据。
