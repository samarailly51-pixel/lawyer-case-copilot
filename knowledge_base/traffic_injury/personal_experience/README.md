# 个人经验知识库预留

此目录当前为空，不包含虚构办案规则。后续只放入经过脱敏、核验、标注地区和有效期的经验资料，并通过统一 Retriever 接口使用。

建议每份资料在正文顶部包含以下元数据：

```yaml
title:
source_type: personal_experience
jurisdiction:
applicable_case_stage:
effective_from:
reviewed_at:
owner:
contains_real_case_data: false
anonymization_checked_by:
```

禁止放入未经授权的客户身份信息、原始病历、联系方式、账号、证件号码或可反向识别当事人的事实组合。
