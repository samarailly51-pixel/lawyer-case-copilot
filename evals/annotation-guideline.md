# 真实脱敏案件标注指引（待项目所有者确认）

> 本文件提供结构和流程，不填写、不推测任何真实办案规则或客户信息。

## 1. 准入条件

- 案件材料已获得合法授权；
- 已完成姓名、联系方式、证件号、地址、病案号、车辆号牌等直接标识符脱敏；
- 标注文件与原材料使用内部随机编号关联；
- 不把真实材料提交到公开 Demo、公共代码仓库或未授权模型服务；
- 标注人员和复核律师已确认数据使用范围、保存周期与删除责任。

## 2. 双人复核流程

1. 标注人员按照字段 Schema 标注事实、事件、引用位置和期望规则输出；
2. 复核律师确认业务含义、适用边界和强制人工复核项；
3. 分歧状态保持为 `disputed`，不得通过多数意见自动覆盖；
4. 评测集发布前再次执行脱敏扫描和引用可访问性检查；
5. 每次规则或模型版本变更后重新运行回归评测。

只有同时满足以下机器校验的记录才进入离线评测：`authorization_confirmed=true`、`deidentification_confirmed=true`、标注人与复核人不同、`status=approved`。评测工具不会提供公开上传接口。

## 3. 建议指标

| 维度 | 指标 |
|---|---|
| 材料分类 | 各类别 precision / recall、无法分类率 |
| 事实提取 | 字段级 precision / recall、来源精确匹配率 |
| 时间线 | 日期准确率、事件遗漏率、冲突发现率 |
| 医疗费用 | 金额和票据号准确率、重复及缺失发现率 |
| 风险规则 | 命中率、误报率、漏报严重度 |
| 人工复核 | 接受率、修改率、关键字段驳回率 |
| 效率 | 单案处理时间、材料定位时间、复核时间 |
| 安全 | 无来源输出拒绝率、敏感信息外发和注入拦截结果 |

指标阈值必须由项目所有者与试点律师共同制定，仓库不预设或虚构业务准确率。
